## ▶ Open one. It runs.

No install, no signup, no backend. Every link below is a real thing running in your browser right now.

<table>
<tr>
<td width="50%" valign="top">

### 🏟 [ESSPN](https://frankyface.github.io/SportsSims/)
**A sports network for leagues that don't exist.**
A deterministic Elo/Glicko-2 engine sims a whole season — standings, title races, relegation
drama — then renders each match as a broadcast-styled MP4, encoded **in the browser** with
WebCodecs. Output goes straight to [@EliteSimSPN](https://instagram.com/EliteSimSPN).

`TypeScript` · `Canvas` · `WebCodecs` · no server

</td>
<td width="50%" valign="top">

### 🃏 [blackjack-vision](https://frankyface.github.io/blackjack-vision/)
**A trainer that watches your actual cards.**
Point a webcam at a real table: YOLOv8 reads the cards, the screen shows the mathematically
correct play, the Hi-Lo running/true count, and live win probability. Detection runs
client-side — nothing leaves your machine.

`Python` · `YOLOv8` · `ONNX Runtime Web` · `Raspberry Pi 5`

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🧵 [Satin Studio](https://frankyface.github.io/satin-studio/)
**A free embroidery digitizer, in a tab.**
Draw a design or drop in flat-colour artwork and it becomes clickable *stitch sections* —
change satin / tatami fill / running outline, thread colour, density, pull compensation —
then export a machine-ready **.PES** or **.DST**.

`TypeScript` · binary stitch-format writers · offline

</td>
<td width="50%" valign="top">

### ✏️ [BOSS Blueprint](https://frankyface.github.io/BOSS-Blueprint/)
**Sketch your website, we build it.**
A client-facing design tool: lay out a site like a slide deck, scribble notes over the top
with a pen tool, wire up multi-page navigation, hit Submit and it produces a build package.
Shipping for real clients at [bossolutions.pro](https://bossolutions.pro).

`TypeScript` · canvas editor · zero-account

</td>
</tr>

### 🎲 [Jeopardy](https://frankyface.github.io/Jeopardy/)
**Game night, no build step.**
JSON-driven board with an in-page editor, up to 8 players, Daily Doubles, Final Jeopardy
wagers, `localStorage` persistence — and it still works opened straight off disk with no
internet at all.

`JavaScript` · zero dependencies · offline-capable

</td>

### 🛠 [PolyDock Designer](https://frankyface.github.io/Polydock-Inventory-Designer/)
**Design a dock, know if you can build it.**

`React` · `Vite` · early build

## 🧭 How I work

- **Spec first.** Every repo carries a `master_plan.md` (where it's going) and a `handoff.md`
  (where it actually is). The docs are the source of truth, so any session — mine or an
  assistant's — can pick the project up cold.
- **Done means demonstrated.** Tests, a live URL, or a screenshot. blackjack-vision doesn't
  say "working", it says *183 passing tests and a link you can open*.
- **Ship it free.** Static builds on GitHub Pages, Supabase where state is genuinely needed.
  Most of these cost $0/month to run.
- **Finish things.** Ten live links beat a hundred half-repos.
